Regras Históricas Ativas

O gerador agora usa inteligência estatística avançada extraindo números de Frequência Média.

  • Filtro configurável de Soma (Padrão 130 a 230).
  • Anti-Trincas: Proibido gerar 3 números consecutivos.
  • Rateio Alto: Obriga a presença de pelo menos três dezenas maiores que 31.
  • Sorteio restrito aos números de frequência "Média".

Gerador de jogos

O gerador usa os dados da planilha com filtros históricos, sem SQLite.

define o menor valor permitido para a soma das dezenas de um jogo; qualquer combinação cuja soma total fique abaixo desse limite é descartada.
define o maior valor permitido para a soma das dezenas de um jogo; qualquer combinação cuja soma total ultrapasse esse limite é descartada.
define quantos jogos válidos o sistema deve gerar após aplicar todos os filtros configurados.
